ARS half-day status correction — 27 October 2026

Problem
Submitting an attendance correction unconditionally replaced the day status with Invalid. This wrongly turned completed Half day records black while an ARS was awaiting review.

Fix
- Capture the attendance status before each new ARS submission.
- Preserve Half day and its existing pay decision while the request is Pending. Rejecting the request also preserves Half day. Approving Full day changes attendance to Present and applies the existing approved-hours calculation.
- Missing-punch Invalid records continue to remain Invalid pending approval.
- Payroll independently checks pending ARS requests, so preserving Half day does not accidentally permit payroll finalization before review.
- Read-time compatibility recovers older pending/rejected ARS records as Half day only where both physical punch-in and punch-out exist and the old request has no prior-status metadata. Missing-punch records are not reclassified. No production records are rewritten or migrations run.
- Existing older records without enough evidence of their prior status require administrator correction; the code does not invent missing punch times or a historical pay decision.
- Teacher/admin dialog wording now explains that submitting or rejecting a request retains the existing attendance status.
