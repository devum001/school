Attendance setup and arrival-only half-day rules — 2 November 2026

User decision: use arrival cutoff only, not minimum working hours.

Implemented
- Login creation has a default-on Start attendance automatically checkbox when the staff member is a teacher, the creator has attendance.manage, and the selected role has attendance.self.
- Account, membership, staff link and tracking activation happen in one transaction. An activation error rolls back the new account as well. Opt-out preserves the existing login-only behavior.
- First explicit activation initializes the school's tracking date automatically. A new teacher starts on the latest of today, their joining date and an existing future school tracking date. Earlier dates are never automatically backfilled as absent. Existing linked teachers can use Start attendance without first setting a separate school date.
- School timings/location remain a one-time school setup. Advanced tracking/cutoff fields are collapsed; minimum-hours classification has been removed from the settings UI.
- Automatic punches and administrator time corrections use arrival time only. With lateAfter=10:26 and halfDayAfter=14:26, 11:00–16:00 is Late (included in Present). Only arrival strictly after 14:26 automatically becomes Half Day. Working duration is still recorded.
- Present register/profile/directory counts and filters include Late. Late remains a distinct flag/subset. Half Day is separate. Stacked charts retain disjoint segments so the same teacher is never counted twice in the bar; legend text explains the overlapping Present/Late counts.
- Late rows display Present plus Late badges. Half Day no longer shows an extra Late badge and can show an explanation from the saved attendance record.
- Unreviewed automatic historical half-day records with saved rules are projected using arrival-only classification, without rewriting the database. Explicit administrator decisions and ARS records stay intact. Older records without saved rules are not guessed. Per-day saved arrival cutoffs are preserved when school settings change later.
- Attendance register links now honor the requested date within the selected month.

Compatibility and safety
No database script, migration or data reset is required. Existing halfDayMinutes/fullDayMinutes fields remain for stored-record and older-client compatibility but no longer drive automatic half-day classification. No salary, leave balance, or approved payroll record was rewritten. No credentials/configuration/dependency changes or live database access. Existing uncommitted work preserved via hash checks. No commit/push/deploy.
