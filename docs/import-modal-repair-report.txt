Student import modal layout repair — 2026-10-19

Cause
The preview squeezed many columns into a fixed 800px dialog. The shared error
style added large horizontal margins/padding, while table cells allowed text to
break anywhere. The result was the nearly one-character-wide error in the screenshot.

Changes
- Import-specific modal width up to 1200px, constrained to the viewport.
- Persistent heading/close button with independently scrolling modal content.
- Preview table scrolls horizontally and vertically within a bounded region.
  Result/error and correction columns have explicit minimum readable widths.
- Scoped error spacing, full-width progress, wrapping action controls and responsive
  totals. Other modal layouts retain their existing styles.
- Properly spaced upload controls and explanations of class selection and matching.
- Row correction uses two columns on desktop, one on mobile, scrolling content,
  an accessible close button and an explicit Cancel action.
- Back to file selection accurately labels navigation inside the student modal.
  Shared standalone import jobs retain Back to directory.
- Import validation, permission checks, save behavior and data matching are unchanged.
